# golang_api
Repository to play around with Golang and a simple API

## Notes
When initialising this project create the main.go file and define any dependencies and the functions for the golang application

Run `go mod init example.com/<project-name>` to intialise your `go.mod` sort of a lock file. 

Module reference usually references a github URL
`github.com/user/<golang-package>`

Since example.com is a reserved domain it is generally safe to use for examples and documentation.

This is purely for the purpose of publishing and importing these modules. 

For this project since it is internal I'm coming up with my own garbage name
`go mod init nam.is.cool/golang_api`

As Go will not be fetching this module or anything that it creates it doesn't need to be real just `look` real
